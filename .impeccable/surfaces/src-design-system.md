# san-ui design system

Scope: the whole system (tokens, themes, foundations, components, Storybook). Mode: Operate, with display type for Read and Persuade surfaces built on it. Audience: builders of future apps and those apps' users at a desk, on a phone and on content sites. Constraint: every theme and density meets WCAG 2.2 AA.

## Direction contract

THESIS: A base that behaves like a native platform on the web: content first, chrome that recedes into materials, motion that answers the hand. It refuses the shadcn default of tinted cards inside tinted cards, pill-everything and zoom-95 popovers.

OWN-WORLD: Grouped surfaces (canvas, raised groups, inset rows with leading separators), one accent per app over hue-tinted neutrals, solid status fills, translucent floating materials, system type with size-specific tracking, capsule buttons, concentric continuous radii, critically damped springs.

STORY: A builder picks a theme hue and a density and gets a finished interface; a user meets familiar controls that respond on press and can be swiped away.

FIRST VIEWPORT: The Storybook introduction shows a working settings-style screen: large title, grouped list, segmented control, one filled action.
