# san-ui

One interface for every app: tools and dashboards, consumer apps and content sites. It aims to feel native, the way Apple's platforms do: content first, quiet chrome, motion that springs and can always be interrupted.

<Story of={SettingsStories.Settings} />

## What it stands on

- **Roles, not ramps.** Colors name a job (`bg-surface`, `text-ink-secondary`, `bg-accent`). A theme sets an accent hue and how vivid it is; everything else is derived in OKLCH, at contrast that stays WCAG AA for any hue. A test sweeps all 360 hues in light and dark to prove it.
- **Grouped surfaces.** A tinted canvas with white groups on it, as in a settings screen. In dark mode elevation is lightness. Cards don't nest; inside a card use a List, an inset well or a separator.
- **Density.** `data-density` sizes type, controls and rows: `regular` for a mouse, `comfortable` for touch (the default on touch screens, so every target is 44px), `compact` for dense tools.
- **Springs.** Things that appear grow in with a critically damped spring and leave quickly. Sheets slide in from their edge and drag down to close. Bounce is only for motion a gesture started. Reduced motion cross-fades.
- **Materials.** Menus, popovers and tooltips are translucent panels that grow from their trigger. With reduced transparency or more contrast they turn solid.
- **The system font.** San Francisco on Apple devices, the platform face elsewhere, with tracking that tightens as text grows.

Use the toolbar to switch light and dark, the theme (default, forest, ember, graphite) and the density. Every story should look right in all of them.

Patterns has whole screens built only from library parts, like the one above: a dashboard, a list with search and filters, a detail screen, a long form, sign in, a phone app and a pricing page. Start a new screen from the closest one.

## Using it

The components are copied into your app at `src/design-system/` by the shadcn CLI, so you own them and import them through the `@/` alias. The `@sandilya/ui` package holds only the tokens, themes and the Tailwind theme.

```bash
bun add @sandilya/ui motion
bunx shadcn@latest add https://ui.sandilya.dev/r/san-ui.json
```

```tsx
import { List, ListItem, ListSection, Switch } from '@/design-system';

<ListSection title="Updates">
  <List>
    <ListItem title="Weekly summary" trailing={<Switch />} />
  </List>
</ListSection>;
```

The repository README at [github.com/anand-san/ui](https://github.com/anand-san/ui) has the full setup and the rules.
